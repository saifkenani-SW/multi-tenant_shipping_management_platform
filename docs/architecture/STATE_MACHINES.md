# State Machines

## Purpose

This document defines the valid lifecycle of every Aggregate Root that owns business state.

State transitions are part of the Domain Model.

Only the Domain Layer may perform state transitions.

Application Services request transitions.

Aggregates decide whether transitions are valid.

Invalid transitions must raise Domain Exceptions.

# General Rules

Every Aggregate owns its own lifecycle.

State transitions must always be validated by the Aggregate Root.

Repositories must never change state directly.

Controllers must never change state directly.

Application Services request transitions.

Aggregates approve or reject transitions.

If a transition is not explicitly defined in this document, it is considered invalid.

State Machines are the authoritative source for all business state transitions.
