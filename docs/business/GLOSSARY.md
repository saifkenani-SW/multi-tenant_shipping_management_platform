# Glossary

| Term | Definition |
|------|------------|
| Tenant | An organization or company using the platform |
| Shipment | A package or cargo being transported |
| Dispatcher | User responsible for creating and assigning shipments |
| Consignee | The recipient of the shipment |
| Ledger | Double-entry accounting record of all transactions |
| Waybill | Document containing shipment details and routing information |
| ETA | Estimated Time of Arrival |
| POD | Proof of Delivery |
| RBAC | Role-Based Access Control |
| DDD | Domain-Driven Design |
